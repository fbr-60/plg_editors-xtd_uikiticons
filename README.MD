## Плагин для joomla 6
Позволяет автоматически добавлять иконки Uikit к спискам ul/ol в текстовом редакторе.
** Плагин НЕ создает иконки! **
Он добавляет соответсвтующие классы к спискам ul/ol в текстовом редакторе (TinyMCE или JCE).

Плагин подключается к событию onEditorButtonsSetup. 

Как это работает для контент-менеджера:

1. Вы пишете создаете в редакторе (TinyMCE или JCE) список ul / ol.
2. Клик на любом пункте списка.
3. Нажимаете кнопку "Иконка UIkit".
4. В открывшемся окне выбираете: из списка Иконку, из списка Цвет. 2 чекбкса. Позволяют задать фон для иконки, применить фоновый цвет к тексту строки.
5. Нажимаете "Вставить". К тегу ul/ol автоматически добавляется класс, обеспечивающий оформление списка согласно заданным настройкам.
